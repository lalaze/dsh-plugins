# lalaze's DSH plugins

Generated by `pnpm release:market` from [lalaze/dsh-plugins](https://github.com/lalaze/dsh-plugins). Each directory under `packages/` is a built, install-ready plugin, and `index.json` is a DSH plugin market index (format 1) listing every released version.

To browse and install these plugins in DSH, open **Plugins**, switch on **Custom plugin markets** under experimental plugins, then add this index source on the **Discover** tab:

    https://raw.githubusercontent.com/lalaze/dsh-plugins/market/index.json

Every listed version pins a commit of this branch. Never rewrite or force-push it.
