### 升级时要做的事

- 每台用到终端、TUI 或 worktree 的 DSH：把 Remote Agents 升到 0.2.130，**再安装 Remote Terminals 0.1.0，然后重启 DSH**。只升级不装新插件的话，这三项功能会消失，其余不受影响。
- 用 Autofix 的 DSH 同时升到 0.1.1。
- 远程机器上不需要做任何事：终端保持程序、TUI 附件和 worktree 仍在 `~/.dsh-remote-agents/` 下，正在运行的终端和 CLI 不受影响。

### 这次改动的由来

Remote Agents 三周内从 428 KB 长到 1543 KB，占仓库一半以上的提交。量过之后发现终端、TUI 和 worktree 与对话部分之间只有十几个交叉点，可以独立；文件面板、同步、新建工作区对话框和工作区定位是远程对话本身要用的，留在 Remote Agents。拆分后 Remote Agents 源码 1116 KB，Remote Terminals 327 KB，两者共用的私有包 `packages/remote-core` 94 KB。

## Remote Terminals 0.1.2 — 升级前打开的终端能重新启动

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Remote Terminals | 0.1.1 → **0.1.2** | 升级前在远程工作区里打开的侧边栏终端，DSH 重启后报 `Selected shell is not available in this execution environment`，重试也一样。启动脚本从 `storages/dsh-remote-agents/terminal/` 搬到了 `storages/dsh-remote-terminals/terminal/`，而浏览器记的是完整的旧路径。现在服务端把别的目录下的同名启动脚本换成当前的那个再启动。 |

源码与版本提交：`2ea9025da5810250c495af812760c60550f2cb24`；市场包：`e98766f2275b85dc07ab7598aee6f52aec122f95`；市场索引：`54d5ac4284be2c3fd1722e6503e4688c9c2b693f`。main 与 market 已原子推送，远端分支 SHA 已核对，公开索引已列出 0.1.2。

### 怎么发现的

用户更新后在页面上看到"终端错误：Selected shell is not available in this execution environment"。这句话出自 DSH 自己的终端控制器：`spawn` 收到明确的 `shellPath` 时，只接受它当前提供的路径。页面为了在 DSH 重启后让远程终端的标签页重新启动同一个启动脚本，把完整路径存在浏览器里（`remote-agents.terminal.shell.<终端 ID>`），拆分时这个目录变了，旧路径不再被提供。

"新建终端"记住的 `dsh.terminal.shell` 也可能是旧路径，但 DSH 在那里找不到时会退回第一个 Shell，不会报错；恢复后的终端运行起来时，页面顺带把它改成当前路径，免得在远程对话里新建出本地 Shell。

### 验证

- 新增 2 项测试：旧目录下的三个启动脚本都在当前位置启动，终端 ID 照常传给进程，其他 Shell 原样放行，DSH 不提供的 Shell 仍被拒绝，卸载后 `spawn` 还原；"新建终端"的选择跟到当前路径，用户另选的 Shell 不动。
- 用 Mac mini 上 DSH 0.2.2-rc.1 自带的 `TerminalController.spawn`（子进程用假的）跑旧路径：没有修复时得到同一句报错，有修复时启动的是新目录下的脚本，卸载后恢复报错。
- Remote Terminals 164 项全部通过；类型检查通过。
- 没有在真实页面上验证。

## Game Assets 0.1.2 — 素材网格不再卡顿

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Game Assets | 0.1.1 → **0.1.2** | 装上 0.1.1 后发现素材标签页非常卡，工具栏和文件夹树被滚出屏幕，缩略图迟迟不出。原因：对话有内容后，DSH 让视图区随内容长高、由外层滚动；素材面板写的是 `height:100%`，此时没有约束，网格被撑到所有行的高度（5209 张约 9 万像素），自己从不滚动，虚拟列表把每一行都算作可见，一次渲染几千个格子并同时请求几千张缩略图，远程工作区就在 SSH 上排起几千次运行。现在面板按 DSH 对话区剩下的可见高度（减去下方停靠的输入框）定高，网格自己滚动；网格按“自身、窗口和行”三者的交集计算哪些行在屏幕上，无论哪一层在滚都只画这些行；缩略图改为成批请求（每批最多 32 张、约 6 MB），远程工作区一批只在那台机器上跑一次。 |
