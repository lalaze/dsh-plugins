# 2026-11-06 发布记录

## 插件页顶部不再有横带

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Gallery | 0.1.2 → **0.1.3** | 用户反馈 0.1.2 在桌面版上滚动后，插件页顶部还留着一条毛玻璃带。只要靠半透明底色挡滚动内容，就一定比壁纸暗一截，所以不再铺底色，改为在页头里再画一张同样的壁纸，并按真实壁纸层的位置对齐（页头是 size container，可能成为 `position: fixed` 的包含块，所以靠测量定位）。内容在页头下沿 12px 内淡出，分隔线隐藏。页头出现靠 `animationstart` 发现，不用监听整页 DOM。只有这张壁纸挂上时页头才透明，没挂上就退回 DSH 原来的实底，不会出现内容和按钮叠在一起。 |

验证：用市场上的版本实际安装后，在隔离的 DSH 0.2.2-rc.1 网页版（无头 Chromium）把页头区域和纯壁纸逐像素比对，没滚动、滚动后、离开再回来、模糊 8 加不透明度 0.55 都是 0 像素差异；去掉这张壁纸后同一区域差约 1300 像素，说明这个比对确实能发现问题。发布前的构建还比对了滚动中途、缩小窗口、收起侧边栏，同样是 0 像素，并确认页头按钮能点、点空白处不会点到被盖住的行、移除这张壁纸后实底会回来；用真实照片看过深浅两种主题。0.2.1-rc.5 上没有吸顶页头，不挂这张壁纸，插件页和自动化任务页正常。两个版本控制台都没有报错。Gallery 的单元测试和界面测试通过，新增断言在修改前会失败。

**未验证：** 桌面版。已知限制：依赖 DSH 的 `data-plugin-bar` 和 `--plugin-header-paint-height`，改名后会退回实底，不影响使用；浅色主题下壁纸较亮时，列表的灰色说明文字不好读，这和本次改动无关，没有处理。
