### 已知回归限制

这不是“全仓所有测试通过”的声明。Remote Agents 更广范围回归仍有：4 个离线恢复/审批/删除用例因未完成的 Promise 被取消，2 个 sharing 断言失败，以及一个共享会话清理偶发失败（单独重跑通过）。这些代理/转发生产代码未因本次 Git 发布而修改，也没有弱化断言来掩盖问题。详见 [Git 验收记录](../../packages/git-view/VALIDATION.md)。

本地文件原子 rename 不是针对外部并发写入的系统级 CAS；实际 Desktop/Electron、Windows 及 Linux 本地编辑运行时未在本次验收中覆盖。功能与兼容范围以各插件说明为准。

## 发布方式

源码提交到 `main`，市场安装包及经 DSH 校验器验证的索引提交到只追加的 `market` 分支；使用普通快进推送，不改写既有发布历史。市场索引：

<https://raw.githubusercontent.com/lalaze/dsh-plugins/market/index.json>

本地 `.tgz` 和校验文件保存在忽略的 `dist/release-2026-10-30/`。市场使用固定提交的独立插件目录安装；不是向 npm 发布，也不是安装整个源码仓库。更新第三方插件时按宿主提示先卸载旧版再安装新版。
