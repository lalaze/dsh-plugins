# 2026-11-15 发布记录

## Remote Terminals 0.1.9 — 手机上可以滑动终端，Claude Code 的符号也正常显示了

在手机网页端（dsh.lalaze.com，由 Mac mini 提供）打开 TUI 对话有两个问题：

- **手指滑动终端没有反应。** DSH 自带的 xterm 6 的滚动区域不是浏览器原生的滚动框，也完全不处理触摸，只认鼠标滚轮。在 Mac mini 的真实页面上用模拟的 Pixel 7 打开一个有 381 行历史的 TUI 对话，整屏滑动一行都没动。
- **出现奇怪的符号。** Claude Code 每一步前面的 ⏺ 显示成橙色的表情方块，模式前面的 ⏵⏵ 显示成两个空方框。安卓的等宽字体里没有这些符号：⏺ 只有彩色表情字体里有，⏵ 任何字体里都没有。

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Remote Terminals | 0.1.8 → **0.1.9** | 手指上下滑动终端就能滚动；快速一划，松手后会继续滑一段再慢慢停下，再按一下就停。终端显示自己的历史时（shell，或经典界面的 CLI）滚动这段历史；程序自己画整个屏幕时（全屏 Claude Code、编辑器），或者程序要求了鼠标事件时，它收到的和用滚轮时一样，每滑一行发一次。点一下仍然会聚焦终端、弹出键盘，滑动不会。侧边栏终端和 TUI 对话都生效。<br>在触屏设备上，插件自带 115 个手机没有文字字体的符号，包括 ⏺ ⏵ ⏸ ⏹。它们取自 Noto Sans Symbols 2（SIL Open Font License 1.1），每个缩到正好一个终端格宽，共 6 KB，直接从插件代码加载，不另外请求文件。电脑上的显示不变。 |

源码与版本提交：`4aef245`；市场包：`40fcd8e800feb8caed17923663d0b6e2d5019744`；市场索引：`a83eb58`。

### 验证

- 206 项测试全部通过（新增 12 项），类型检查和构建通过。市场包里的 `lib` 和测试用的构建逐字节相同。
- 把改动注入 Mac mini 的真实页面，用模拟的 Pixel 7 测：慢慢拖 300 像素滚动 19 行（每行 15 像素）；快速一划手指带动 16 行，松手后惯性又滚 32 行。点一下焦点进入终端的输入框，滑动不会。页面不跟着滑动，没有页面错误。WebGL 和 DOM 两种绘制方式都正常。
- 符号：⏺ 和 ⏵ 的宽度是 7.81 像素，字母是 7.83 像素；⏵⏵ 在 WebGL 和 DOM 下都能画出来；字体比终端晚加载时，已经打开的终端会重画，没有错位。

### 未验证

- 真实的安卓或 iOS 设备。上面的结果都来自 Mac 上 Chromium 模拟的手机。
- 全屏 Claude Code 用手指滑动。Remote Agents 的「本地滚动」默认开着，这时不走这条路；关掉后，每滑一行发一次滚轮，Claude Code 每次可能滚不止一行，滚得会比手指快。
- 侧边栏终端用手指滑动。

### 安装

```text
git+https://github.com/lalaze/dsh-plugins.git#40fcd8e800feb8caed17923663d0b6e2d5019744&path:/packages/remote-terminals
```

升级后重启 DSH，手机上刷新页面。只有提供网页的那台 DSH 需要更新；Remote Agents 不用动。

## Workspace Tags 0.3.3 + Remote Agents 0.2.133 — 适配 DSH 0.2.2-rc.3 的添加工作区

DSH 0.2.2-rc.3 新增了一个给其他插件用的工作区选择器（`workspace.picker`），最先用在实验性的「导入 DeepSeek 会话」对话框里。DSH 自带的文件夹选择器现在要等三个「添加工作区」挂载位都在才会装上，而 Workspace Tags 的侧边栏是 rc.1 的副本，只有两个。于是在 rc.3 上装了 Workspace Tags：

- 侧边栏和新会话工作区选择器里，DSH 自带的「添加工作区…」消失（装了 Remote Agents 时它自己的窗口还在，所以看不出来）；
- 导入对话框里点「选择工作区」没有反应。

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Workspace Tags | 0.3.2 → **0.3.3** | 侧边栏副本补上 rc.3 的工作区选择器和它的挂载位，上面两处恢复。新会话和导入对话框里的工作区菜单在 rc.2 及之后重新弹在按钮下方（rc.2 起是弹在旁边）。rc.1、rc.2、rc.3 都能用，`engines.dsh` 不变。 |
| Remote Agents | 0.2.132 → **0.2.133** | 导入对话框里的「添加工作区…」也打开本插件的窗口，可以选远程机器上的文件夹。三个挂载位分别注册，rc.3 之前的 DSH 上不受影响。 |

源码与版本提交：`fd45d8c`、`3bb2a44`；市场包：`19bc809360199c5246809dcc9f43c7cfc471cdaa`；市场索引：`68c495d`。

### 验证

- Workspace Tags 410 项测试通过，其中搬来了 rc.3 自带的 `workspace-picker-factory` 测试，直接跑在我们的侧边栏副本上：不改时 3 项全失败，改后全过。类型检查和构建通过。
- Remote Agents：新增 rc.3 之前、之后两种 DSH 的挂载位测试；类型检查、构建通过。整套测试里 `relay.test.ts` 有一项在满负载时失败、一项被取消，单独跑这个文件两次都是 26/26，是已知的时序不稳，与本次改动无关。
- 在 rc.3 的真实 DSH 上（隔离的 DSH_HOME，网页端）：
  - 旧版 0.3.2：侧边栏没有添加按钮，新会话菜单只有「默认工作区」，导入对话框的选择工作区点了没反应——三个现象都复现。
  - 新版：侧边栏添加按钮回来；新会话和导入对话框的菜单都有「添加工作区…」，弹在按钮下方；只装 Workspace Tags 时打开 DSH 的「选择工作区目录」。
  - 加上 Remote Agents 0.2.133 和 Remote Terminals 0.1.9：导入对话框里的「添加工作区…」打开 Remote Agents 的窗口，选一个文件夹后工作区出现在侧边栏，并在导入对话框里被选中。没有页面错误。
- 同一套环境换成 rc.2、rc.1 的运行时：添加工作区正常，菜单都在按钮下方。
- 市场包里两个插件的 `lib` 和上面测试用的构建逐字节相同。

### 未验证

- 桌面版（它用原生的文件夹选择框，网页端用的是 DSH 的目录浏览）。
- 有远程机器时导入对话框里的「远程机器」标签页（测试环境没配主机，只看到了「本机」「基于项目」）。
- 真正导入一份 DeepSeek 导出文件。

### 安装

```text
git+https://github.com/lalaze/dsh-plugins.git#19bc809360199c5246809dcc9f43c7cfc471cdaa&path:/packages/workspace-tags
git+https://github.com/lalaze/dsh-plugins.git#19bc809360199c5246809dcc9f43c7cfc471cdaa&path:/packages/remote-agents
```

先更新这两个插件（在 rc.2 上也能用），再把 DSH 升到 0.2.2-rc.3。共用会话的 DSH 要一起升级。更新后刷新页面；桌面版请重启 DSH。
