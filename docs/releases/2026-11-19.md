## 远程终端 0.1.21 — 新开的 TUI 顶上不再出现 `^[[I^[[O`

用户新开一个 Claude Code TUI，看到 Claude 的标志前面多了 `^[[I^[[O`（截图）。这是 0.1.20 带来的问题：页面不管 CLI 有没有开启焦点报告都会认领画面，TUI 出现在眼前 300 ms 后发 ESC[I + ESC[O。新开的 TUI 这时还在启动，DSH 的 PTY 仍是普通的回显模式，要等 attach 客户端连上 holder 后执行 `stty raw -echo` 才关掉回显，认领就被内核原样回显成 `^[[I^[[O`。实测：在独立的 PTY 里像 DSH 那样运行 hub 上装的 `Remote Claude` 启动器（新 holder），回显一直持续到 0.616 s，0.303 s 发出的认领被回显，紧接着就是 Claude 的输出，与截图一致。CLI 没有收到这些字节：attach 客户端在 CLI 没开焦点报告时把它们丢掉了。0.1.19 及以前不会这样，因为那时页面只在 CLI 开启焦点报告后才认领，而那时终端已经是 raw 模式。

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| 远程终端 | 0.1.20 → **0.1.21** | **主机在终端里画出内容之前，页面不认领画面：**`claimScreen` 新增 `drawn`，光标还在原点且没有滚动过（新终端的状态）时什么都不发；拿不到光标位置的 xterm 视为已画出，保持原行为。DSH 只把 PTY 的输出写进这个 xterm（`dsh-client-ui-sidebar-terminal` 的 `render.frame`），所以光标没动就表示启动器还没输出任何东西。不会漏掉认领：客户端加入 holder 时会按它的 hello 取得画面大小。 |
