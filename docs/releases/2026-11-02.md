## 共享对话在本机接着聊、手机查看后台任务

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Remote Agents | 0.2.66 → **0.2.67** | 其他 DSH 在共享机器上开的对话自动成为本机主对话：放进它所在的远程工作区，沿用标题、CLI、模型和权限（本机没有对应权限预设时取更严格的），打开时先用一整块显示已保存的历史（很长时只显示最近若干轮），不给 CLI 发任何内容；在这里发消息接着同一个 CLI 会话并接管它，另一个 DSH 中仍在运行的回合接在历史后面继续显示。已归档的会话和 DSH 智能体分派的任务不建对话，删除的对话不会再加回来。主对话发消息时不再把 CLI 自己的回复当作上下文发回给它（过去每条消息都会附带上一条完整回复）。新增 `remoteAgentsTasks` 服务，供其他插件列出、查看和指挥没有 DSH 对话的会话 |
| Mobile | 0.1.1 → **0.2.0** | 新增“后台任务”：机器上装有 Remote Agents 0.2.67 起，列出没有 DSH 对话的远程 CLI 会话（分派的任务、从“打开会话”启动的会话），等待处理的排最前，其次是运行中的；打开后查看历史并实时跟随，可发消息（运行中发送即打断）、停止和批准工具调用，分派的任务链接回分派它的对话 |

验证：`dsh-remote-agents` 新增 6 项测试通过；全量测试中失败和取消的都是中继相关项，在未改动的 main 上同样失败，另有两项只在全量运行时偶发超时，单独运行通过；类型检查与构建通过。`dsh-mobile` 23 项测试通过，类型检查与构建通过，手机界面用 Playwright 在模拟数据上截图检查（列表、运行中、待审批、深色模式、发送）。两者已部署到 Mac mini 上的 mobile DSH（0.2.1-rc.5）：MacBook 开的 21 个共享对话都接成了主对话并显示历史；经 `relay.lalaze.com` 用只读模拟手机读到 8 个分派任务及其历史，只读手机的指令被拒绝。首次部署时发现真实 DSH 与测试不同的三处（通知后追加的上下文消息、没有只读权限预设、启动时共享记录尚未连上）并已修复。未实测：在接过来的对话里实际发消息接管会话、在真手机上批准后台任务。
