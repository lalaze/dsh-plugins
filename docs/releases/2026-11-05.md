# 插件发布记录 — 2026-11-05

## Claude 对话运行时能看到更多

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| Remote Agents | 0.2.94 → **0.2.95** | 用户反馈 Claude 对话中途看到的东西太少，经常跑完才能看全。输出其实是实时到达的，问题在显示：工具卡片要等回复结束才写入；Opus 5.5 把约 100 字的进度说明写成思考块，而 DSH 把同一步的思考都折叠在“已完成分析”下面，一整轮 Claude 在 DSH 里又只算一步。自 11 月 1 日起，60 秒以上的 173 个对话轮里，没有新正文的最长时段中位数是 144 秒，最慢的 10% 超过 549 秒。现在 Claude 的进度说明直接显示在回复里并保留，每句一段，单块超过 1000 字的部分仍按思考折叠（真实日志里 836 段最长 395 字）。回复底部加一行状态，比如 `正在运行 Bash · npm run build`，只在运行中显示，从不保存，按停止也不会：DSH 按块关闭时的内容保存，之后的文字只显示不入库，再次关闭同一块就能撤回。子智能体和团队成员的回复就是结果，进度说明仍然折叠，状态行照常显示。Codex 和其他 CLI 不变。 |
| Mobile | 0.3.4 → **0.3.5** | 手机的实时草稿改为按块处理，和 DSH 聊天一致，否则上面的状态行会一条条叠起来。要和 Remote Agents 0.2.95 一起更新。 |

验证：在隔离的 DSH 0.2.1-rc.5 网页版（无头 Chromium，SSH 到本机）用真实的 Claude Code（Opus 5.5）实测通过：写了正文和还没写正文时显示状态行、运行中按停止、运行中刷新页面、重启后重新打开已保存的会话，保存的记录里都没有状态行；xhigh 强度下写在思考块里的进度说明会实时显示。用户反馈那一轮的真实日志回放也正常。Remote Agents 新增 9 项测试，全量 523 项中通过 501 项、失败 2 项、取消 19 项；干净的 HEAD 上是 514 项中通过 492 项、失败 2 项、取消 19 项，只差一个偶发用例：这边多失败的 `sessions recorded before sharing…` 单独跑时两边都通过，那边多失败的是 `a tag change here triggers a sync on its own`。Mobile 新增 1 项，全量 27 项通过。

实测中修掉的问题：还没写正文就先跑工具时，占位块原本存成空的 reasoning，但 `dsh-llm-deepseek` 会把它原样发出去，换模型时可能出错，所以改存空的 text。

**未验证：** 桌面版。已知限制：工具卡片仍要等回复结束才能展开；Claude 还在生成工具参数时没有状态行（写文件这段中位数约 17.5 秒，最长 345 秒）；运行中的图片仍只显示文件名，原因未查；部分长对话轮开头最多有约 81 秒没有输出（第 90 百分位），原因未查；还没写正文就先跑工具的回复，跑完后正文上方多约 16 像素空白。
