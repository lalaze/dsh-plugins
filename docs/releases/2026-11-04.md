| 插件 | 市场旧版 → 本次版本 | 内容 |

| Remote Agents | 0.2.78 → **0.2.79** | 只改设置界面，功能不变。远程机器列表以前每台机器都一直摊开共享开关和一排 6 个 CLI 勾选，几台机器就拉得很长。现在每台机器默认折叠成一行：显示名字、连接、状态、是否共享和模型数，并用一行小字概括启用了哪些 CLI；点左侧箭头展开才显示共享开关和各 CLI 的勾选，错误信息始终可见。每台机器的 测试连接、刷新模型、移除 收进右侧的 ⋯ 菜单，不再一排三个按钮，移除照旧带二次确认。有机器时"添加机器"表单收起成一个按钮，需要时再展开（没有机器时仍直接显示表单）。团队预设里的成员和任务也改成可折叠卡片：编辑已保存的预设时默认只看摘要（成员显示"名字 → CLI 模型"，任务显示"id → 负责人"），新建预设或新加的成员/任务自动展开。菜单沿用会话选项菜单的点击外部或 Esc 关闭 |
