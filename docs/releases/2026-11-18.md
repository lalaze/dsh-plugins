# 2026-11-18 发布记录

## 远程终端 0.1.19 — TUI 对话加了 Esc 按钮，手机上能关弹窗、中断一轮

用户在手机上用 TUI 对话，打开 Claude Code 的 `/usage` 后关不掉：「手机端不好按 esc 退出」。手机键盘没有 Esc 键，TUI 右下角只有回形针和渲染两个按钮，手机上也就没法中断正在跑的一轮。

| 插件 | 市场旧版 → 本次版本 | 内容 |
| --- | --- | --- |
| 远程终端 | 0.1.18 → **0.1.19** | **Esc 按钮（只在触屏上）：**TUI 对话右下角、回形针左边，32 px，样式同另外两个按钮。点它用 xterm 的 `input('\x1b', true)` 把 Esc 当作用户按键送进终端，和按键盘上的 Esc 一样到达 CLI（终端回到底部的行为也一样）；按下不抢焦点，键盘保持原样。不能输入的页面（另一处在打字）发不出去，和按键一样。`pointer: coarse` 以外不显示。新文件 `src/client/tui-keys.tsx`。 |

源码与版本提交：`b4b3352`；市场包：`0729be0104783ca999f6f8b160e00bc01941bd18`；市场索引：`1b594fc`。不需要重启，手机上刷新页面后生效。

### 验证

- 远程终端类型检查、238 项测试（新增：点按钮把 Esc 作为用户输入送进终端、按下不抢焦点、还没有终端时什么也不做、只在触屏显示）、构建通过；市场包 `lib` 与本地构建逐字节相同，`client.js` 与在真实实例上测过的构建逐字节相同。
- 真实 DSH 0.2.2-rc.3 实例，模拟 Pixel 7，本机 Claude Code 2.1.327（Haiku 4.5）：在 TUI 里打 `/usage` 打开设置的用量页，点 Esc 后弹窗关闭，Claude Code 显示 `Settings dialog dismissed`，回到输入行；焦点始终在终端的输入框；三个按钮从左到右 Esc、回形针、渲染，各 32 px，不重叠。桌面上 Esc 不显示，另两个按钮不变。页面无报错。
- 未验证：真手机（Android Chrome、iOS Safari）、深色主题、Codex 和 Antigravity 的 TUI（它们同样把单独的 Esc 字节当作 Esc）。
