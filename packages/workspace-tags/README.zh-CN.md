# DSH 工作区标签

[English](README.md) | **简体中文**

支持英文和简体中文，跟随 DSH 的语言设置实时切换。

`dsh-workspace-tags` 为 DeepSeek Harness 侧栏中的工作区添加带颜色的标签和一排可按标签筛选侧栏的标签切换按钮，并在侧栏视图选项的**分组方式**中增加两项。

侧栏标题下方的**全部**和每个标签各一个按钮，决定侧栏显示哪些工作区，对所有分组方式都生效，因此“工作”“个人”这类标签可以当作互相独立的空间使用。再次点击已选中的按钮即回到“全部”。未选中的按钮会显示其中有几个会话需要你查看（等待你处理，或已结束而你尚未打开），只要有等待处理的就显示为橙色。搜索仍覆盖所有工作区；打开另一个空间中的搜索结果会切回“全部”。

- **按标签**：每个标签一个分区，按名称排序，最后是**未加标签**。带多个标签的工作区会出现在每个对应分区中。
- **按状态**：**等待你处理**（有 Agent 在等待审批、计划审阅或回答）、**已完成**（有会话已结束而你尚未打开）、**运行中**（有 Agent 正在执行，包括通过子 Agent），最后是**空闲**。只要工作区有任意会话正在运行，它就只出现在**运行中**，并保留该工作区的所有会话，和侧栏一样超出部分收在“展开其余”后面；分区角标只统计正在运行的会话。没有运行会话时，工作区会出现在其会话符合的各个状态中，每个分区只列出对应状态的会话。**空闲**还包含没有会话的工作区，按工作区计数（其他分区按会话计数），默认折叠。每种状态有各自的图标；Agent 开始或结束时分区实时更新。

折叠的工作区行会显示其会话的状态：需要你查看的会话数徽标，或仅在运行时显示加载图标。右键点击工作区，或在其 **⋯** 菜单中选择**标签…**，即可勾选标签、新建标签（名称和颜色）并添加到该工作区，或打开**管理标签…**重命名、修改颜色或删除标签。在任何分组方式下，工作区的标签都以小圆点显示在行尾。分区可以折叠；分组方式、折叠状态和选中的标签按钮按浏览器分别保存。分区内的工作区保持侧栏原有顺序；由于同一工作区可能出现在多个分区，请在“按工作区”分组下拖动调整顺序。

标签保存在 DSH 主机的 `~/.dsh/storages/dsh-workspace-tags/tags.json`（设置了 `DSH_HOME` 时位于其下），同一主机的桌面应用和远程 Web 客户端共用；其他客户端的修改会在 30 秒内或窗口重新获得焦点时同步。在侧栏中删除工作区会一并移除它的标签。

构建并安装：

```sh
pnpm --filter dsh-workspace-tags check
pnpm --filter dsh-workspace-tags pack:plugin
dsh plugin --profile web add "$PWD/dist/dsh-workspace-tags-0.1.8.tgz"
```

需要 DSH 0.2.1-rc.3 或之后的 0.2 版本。

## 0.1.8 更新说明

- “运行中”与侧栏一样，把工作区的其余会话收在“展开其余”后面；正在运行和需要处理的会话始终显示。
- 按标签或状态分区时，工作区行及其会话相对分区标题缩进一级。

## 0.1.7 更新说明

- 运行中的工作区保留所有会话，同时不在其他状态分区重复显示该工作区。
- “运行中”角标仅统计正在运行的会话；折叠的工作区行仍显示等待处理或尚未查看的完成状态。

## 如何替换侧栏

DSH 的侧栏工作区浏览器（`@deepseek-ai/dsh-client-ui-workspace`）没有为工作区行或分组方式提供扩展点，因此本插件包含一份取自 DSH 0.2.1-rc.3 的副本并加入标签功能，同时通过 bundle patch 停用自带的浏览器。浏览器的其余功能，包括搜索、置顶、归档、拖动排序、快捷键，以及 dsh-remote-agents 远程工作区等插件提供的**添加工作区**流程，都与 DSH 一致。卸载本插件即恢复自带的浏览器。

这份副本跟随其来源的 DSH 版本。DSH 更新后，在本插件更新之前侧栏保持该版本的浏览器行为；副本如何与 DSH 保持同步，以及 DSH 拒绝加载插件时如何处理，见 [docs/upstream.md](docs/upstream.md)。
