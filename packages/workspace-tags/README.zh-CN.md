# DSH 工作区标签

[English](README.md) | **简体中文**

支持英文和简体中文，跟随 DSH 的语言设置实时切换。

`dsh-workspace-tags` 为 DeepSeek Harness 侧栏中的工作区添加带颜色的标签和一排可按标签筛选侧栏的标签切换按钮，并在侧栏视图选项的**分组方式**中增加两项。

侧栏标题下方的**全部**和每个标签各一个按钮，决定侧栏显示哪些工作区，对所有分组方式都生效，因此“工作”“个人”这类标签可以当作互相独立的空间使用。再次点击已选中的按钮即回到“全部”。未选中的按钮在其中有会话运行时显示加载图标，并显示其中有几个会话需要你查看（等待你处理，或已结束而你尚未打开），只要有等待处理的就显示为橙色。未连接统一展示提供方时，搜索仍覆盖所有本机工作区；打开另一个空间中的结果会切回“全部”。

- **按标签**：每个标签一个分区，按名称排序，最后是**未加标签**。带多个标签的工作区会出现在每个对应分区中。
- **按状态**：**等待你处理**（有 Agent 在等待审批、计划审阅或回答）、**已完成**（有会话已结束而你尚未打开）、**运行中**（有 Agent 正在执行，包括通过子 Agent），最后是**空闲**。只要工作区有任意会话正在运行，它就只出现在**运行中**，并保留该工作区的所有会话，和侧栏一样超出部分收在“展开其余”后面；分区角标只统计正在运行的会话。没有运行会话时，工作区会出现在其会话符合的各个状态中，每个分区只列出对应状态的会话。**空闲**还包含没有会话的工作区，按工作区计数（其他分区按会话计数），默认折叠。每种状态有各自的图标；Agent 开始或结束时分区实时更新。

折叠的工作区行会显示其会话的状态：需要你查看的会话数徽标，或仅在运行时显示加载图标。右键点击工作区，或在其 **⋯** 菜单中选择**标签…**，即可勾选标签、新建标签（名称和颜色）并添加到该工作区，或打开**管理标签…**重命名、修改颜色或删除标签。在任何分组方式下，工作区的标签都以小圆点显示在行尾。分区可以折叠；分组方式、折叠状态和选中的标签按钮按浏览器分别保存。分区内的工作区保持侧栏原有顺序；由于同一工作区可能出现在多个分区，请在“按工作区”分组下拖动调整顺序。

标签保存在 DSH 主机的 `~/.dsh/storages/dsh-workspace-tags/tags.json`（设置了 `DSH_HOME` 时位于其下），同一主机的桌面应用和远程 Web 客户端共用；窗口可见时，其他客户端的修改会在 3 秒内同步，窗口重新获得焦点时也会同步。其他主机插件可以通过 `workspaceTags` 服务读取和替换标签；[Device Sync](../device-sync/README.zh-CN.md) 借此与已配对的机器共享标签。在侧栏中删除工作区会一并移除它的标签。

构建并安装：

```sh
pnpm --filter dsh-workspace-tags check
pnpm --filter dsh-workspace-tags pack:plugin
dsh plugin --profile web add "$PWD/dist/dsh-workspace-tags-0.2.0.tgz"
```

需要 DSH 0.2.1-rc.3 或之后的 0.2 版本。

## 0.2.0 统一展示

> Device Sync 已于 2026-11-02 移除。`sidebar.workspaces.presentation`、`sidebar.workspaces.viewOptions` 等插槽仍保留；没有提供方时侧栏只显示本机，与 0.1.10 的行为一致。以下及更早的说明按发布时的原文保留。

工作区“最近更新”使用原始当前成员的最大更新时间，在搜索、归档、隐藏及子会话等显示过滤前固定；未展示的本机可复用空白会话也贡献排序时间，但不会因此显示出来。镜像已删除历史仍可阅读，但不贡献当前工作区排序。

首次读取同步历史时在统一列表头部显示加载提示，不提前断言“无匹配”；读取错误保持明确提示，提供方退出后恢复普通本机空态。运行状态将 waiting 视为正在运行，并从现有同设备直接子会话状态推导父会话的子智能体活动（不受子会话显示开关影响），不扩展同步协议。

配合 **Device Sync 0.2.0**，使用一个所属设备限定身份的展示集合处理本机与镜像工作区/历史；移除设备下拉框与远端专区。工作区、目录树、平铺、标签和状态视图共用筛选、搜索、排序、计数和空态。已有项目标签不改名、不合并、不重分配，同名路径不视为同一工作区。

搜索中保留项目标签行，合并本机原有全文/元数据与镜像元数据结果，并明确提示能力差异；没有 Device Sync 时保留原有本机跨项目搜索行为。最近更新时间跨设备排序；手动顺序使用原所属机器工作区序号及稳定限定键，不偏向本机。不提供新的全局同步拖动顺序；只保留安全的原生本机拖动，禁止跨设备放置，绝不把镜像 ID 写入原生顺序库。未导出的本机置顶、未读完成等状态不会被捏造到镜像。

新的 `sidebar.workspaces.presentation` 仅提供无列表界面的客户端桥接；先合并再渲染，不拼接两个列表。真正的原生节点保留原生操作，镜像分支不能实例化本机操作槽或控制器。提供方退出/出错会使旧操作失效并保持本机列表。原有滑杆菜单显示已隐藏/子智能体选项。镜像就地标签编辑保留部分成功确认、固定编辑器、失败重试与筛选切换取消保护，详情见 Device Sync 文档。

自动测试覆盖双方身份互换后的集合/顺序、同 ID 碰撞、原生交互、同 ID 主面板回切、过期搜索、跨设备拖动拒绝和标签编辑；真实双机浏览器验收仍是独立部署步骤。

## 0.1.13 更新说明

- 在工作区标题旁**原有**滑杆菜单中增加可选的 `sidebar.workspaces.viewOptions` 组件槽。Device Sync 0.1.4 在“远端会话”分组中提供已隐藏/子智能体会话显示选项；菜单沿用原生菜单行样式，贡献方在菜单生命周期之外保存状态。
- 设备选择与项目标签两行保持不变；没有贡献方时不出现空的远端分组或分隔线。不改变执行或主机会话库行为。

## 0.1.12 更新说明

- 顶部明确区分**项目标签**（全部/未打标签/已有标签）与 Device Sync 0.1.3 提供的独立**设备**下拉框。设备按所属 DSH 身份区分，不是标签名称或 SSH 主机；同时筛选原生本机与镜像工作区列表，不改变当前会话或执行位置。设备槽占用状态、加载/错误回退确保提供方不可用时本机工作区不会被永久隐藏。
- 未打标签是独立视图状态，不加入标签目录；忽略已删除标签的旧归属。保留用户所有已有标签、名称和分配，标签仍在机器间共享。全局搜索继续在所选设备内跨项目搜索，搜索时暂时隐藏项目标签行。
- 本机分组方式不变。活动徽标仍只统计本机，远端单设备视图下隐藏。Device Sync 提供远端行标签名称及就地保存/取消编辑，只发送明确的分配修改；部分写入、取消与已关联工作区的语义见其说明文档。
- 设备控件单行、项目标签横向滚动；只看远端设备时远端分支使用完整列表空间。

## 0.1.11 更新说明

- 在普通工作区浏览器中提供可选的 `sidebar.workspaces.remote` 客户端扩展槽，传入当前标签 ID、搜索词和归档筛选。Device Sync 0.1.2 在此显示按所属设备区分的远端工作区与会话，并打开真实主区域对话面板；未安装 Device Sync 时不改变本机浏览行为。
- 远端节点不注册进原生主机工作区/会话库，也不进入本机行操作菜单。远端对话面板激活时，本机新建/添加/分叉/归档/改名快捷键不会操作之前的本地会话；回到本机对话后恢复正常。
- 远端分支保留设备/工作区层级，本机分组方式和活动计数不变；远端工作区的分组分配仍在 Device Sync 设置中操作。

## 如何替换侧栏

DSH 的侧栏工作区浏览器（`@deepseek-ai/dsh-client-ui-workspace`）没有为工作区行或分组方式提供扩展点，因此本插件包含一份取自 DSH 0.2.1-rc.3 的副本并加入标签功能，同时通过 bundle patch 停用自带的浏览器。浏览器的其余功能，包括搜索、置顶、归档、拖动排序、快捷键，以及 dsh-remote-agents 远程工作区等插件提供的**添加工作区**流程，都与 DSH 一致。卸载本插件即恢复自带的浏览器。

这份副本跟随其来源的 DSH 版本。DSH 更新后，在本插件更新之前侧栏保持该版本的浏览器行为；副本如何与 DSH 保持同步，以及 DSH 拒绝加载插件时如何处理，见 [docs/upstream.md](docs/upstream.md)。
