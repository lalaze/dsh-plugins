# TAPD

[English](README.md) | **简体中文**

把 TAPD 作为[自动修复](../autofix/README.zh-CN.md)的一个缺陷来源：你 TAPD 名下的待处理缺陷（连同描述里的图片）送进去，修复每推进一步，状态和评论回写回来。这个插件只和 TAPD 打交道；worktree、模型、检查和验收都由自动修复负责。

> 尚未发布：这个包是私有的，插件市场会跳过它。

## 设置

**设置 → 自动修复 → 缺陷来源 → TAPD**（dsh-autofix 为 0.1.1 或更早版本、或者没有安装时，仍是单独的 **设置 → TAPD** 页，并提供安装「自动修复」的按钮）：

- **登录**：个人访问令牌，或 API 帐号和口令。保存在 `~/.dsh/storages/dsh-tapd/settings.json`，只有你能读取，不会回传给页面。
- **拉取哪些缺陷**：你的 TAPD 名字（和缺陷“处理人”里显示的一致）、TAPD 项目，以及要拉取的状态。状态可以填 API 值（`new`、`reopened`），也可以填项目里显示的名字（`待处理`）。
- **回写什么**：验收后的缺陷状态（默认 `resolved`）、任务开始时的状态（可选），以及修复等你验收时是否在缺陷下评论。

**测试** 会用已保存的设置向 TAPD 查询你名下的待处理缺陷。

## 会写到 TAPD 的内容

| 时机 | 写入 |
| --- | --- |
| 任务开始 | 进行中状态（设置了才写） |
| 修复等你验收 | 一条评论：分支、提交、检查结果（开启评论才写） |
| 你通过验收 | 完成状态，以及一条带合并提交或已推送分支的评论 |

缺陷标题是中文时评论用中文，否则用英文。最后一步 TAPD 拒绝的话，自动修复会留着这次回写，并提供 **重新回写**。

## 要求

- DSH 0.2.2-rc.1 或更新版本，以及 `dsh-autofix`。
