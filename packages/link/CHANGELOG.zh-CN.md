# 互联（DSH Link）更新日志

[English](CHANGELOG.md) | **简体中文**

按版本从新到旧列出变化及升级后需要做的事。

## 0.1.11 — 其他机器的侧栏也延伸到桌面窗口顶部

只需更新显示其他机器的那台电脑（你在它的桌面窗口里切换），刷新一次窗口；其他机器不用动。

- 桌面 App 里，另一台机器的左侧栏从标题条下方才开始，上面露出一截壁纸（或页面背景），侧栏右边的分隔线也短了一截。现在侧栏一直延伸到窗口按钮下面，和本机页面一样；侧栏里的内容位置不变。

## 0.1.10 — 机器菜单变矮，每台机器一行

更新每台电脑，不需要重启，刷新一次页面。

- 机器菜单变矮：每台机器只占一行，只有需要时才在行尾写一句短说明（本机、1 个运行中、连不上、离线）；不再在每台机器下面写「空闲」，绿点已经表示。去掉「刷新页面」「重启 DSH…」上方的机器名标题，它们作用于打勾的那台。

## 0.1.9 — 机器菜单改成 DSH 自带菜单的样子

更新每台电脑，不需要重启，刷新一次页面。

- 机器菜单改成和 DSH 自带菜单一致：底部的自绘图标按钮换成两行普通菜单项「刷新页面」「重启 DSH…」，用 DSH 自己的图标，上方有一个写着当前机器名的小标题（与 DSH 的视图选项、工作区菜单同样的排法）；机器下方的说明文字也改用 DSH 菜单说明的字号和颜色。

## 0.1.8 — 不再运行插件的机器自动移出列表；菜单操作换成图标

更新每台电脑，不需要重启，刷新一次页面。

- Tailscale 账号下某台电脑删掉了 DSH 或本插件（列表里显示「对方没有运行本插件」），它的端口连续十分钟没有应答后就从机器列表里移除；以后重新装上插件会自动出现。睡眠或关机的电脑照旧保留。
- 机器菜单底部的「重新加载」「重启 DSH」两行改成机器列表下方同一行的两个图标按钮，悬停提示里写着是哪台机器。

## 0.1.7 — 使用量统计可以把每台机器加在一起

更新你会看它页面的每台电脑，并重启那里的 DSH 让服务生效；其他机器不需要更新。

- 本机 DSH 上的其他插件现在可以访问各台机器：`dshLink` 服务列出机器，并经机器的监听端口向它的 DSH 发 GET 请求（用那台机器自己的登录，和打开它的页面一样）。使用量统计 0.1.20 用它在标题栏和统计窗口里统计每台机器的用量。

## 0.1.6 — ⌘R 重新加载正在看的机器

更新显示其他机器的那台电脑（你在它的桌面窗口里切换），刷新一次窗口；菜单项需要其他机器也更新。

- 桌面 App 里，在另一台机器的页面上按 ⌘R 没有任何反应：App 把 ⌘R 交给 DSH 的右侧边栏，从不重新加载窗口，而窗口里的机器页面是网页，没人处理这个按键。现在在另一台机器的页面上按 ⌘R，会重新加载那台机器的页面，窗口和其他机器的页面保持不动。Ctrl+R 照常交给页面，终端要用它搜索历史。
- 机器菜单里加了「重新加载 {name} 的页面」，重新加载当前这个页面；在桌面窗口里只重新加载那台机器的页面。哪台机器装了这个版本，它的页面上才有这一项。

## 0.1.5 — 桌面标题条后面显示壁纸

只需更新显示其他机器的那台电脑（你在它的桌面窗口里切换），刷新一次窗口；其他机器不用动。

- 桌面 App 里，另一台机器页面上方的标题条改成透明。那台机器的页面铺满整个窗口，内容从标题条下方开始，所以图库壁纸（或页面自己的背景）会延伸到窗口按钮和机器名后面，和本机页面一样。它的菜单和对话框不会被标题条挡住，全屏时标题条照旧隐藏。

## 0.1.4 — 桌面窗口的问题，HTTP/1.1 下不再卡住

每台电脑都要更新，不用重启，刷新一次窗口。

- 桌面 App 里，另一台机器的页面不再把标志画到 macOS 窗口按钮下面：上方多一条细标题条，放窗口按钮、可以拖动窗口、显示当前机器名。全屏时不显示。
- 作为整个窗口打开的机器页面（按地址打开的，或者旧版留下后刷新的）会回到本机页面，再在本机页面里显示那台机器，来回切换就不再整页加载。用「直接打开」打开的保持原样。
- 经 HTTP/1.1（普通 `http://` 地址）打开时默认不再保留页面：浏览器对一台主机最多开 6 个连接，每个 DSH 页面大约占 4 个，多开一个页面两边都会卡住。这时切换照旧整页加载，仍可以在「设置 → 互联」里打开。HTTPS（HTTP/2，比如手机用的地址）和桌面 App 照常保留页面。
- `/dsh-link/diag` 列出本机窗口报告的切换情况（连接方式、另一台机器的页面多久起来），可以经另一台机器的挂载读取。

## 0.1.3 — Tailscale 误报离线的机器照样显示

- Tailscale 说某台机器离线时，只要本机以前见过它，仍会试连一下，连得上就算在线。Tailscale 的在线标记是协调服务器的看法：一台电脑的 Tailscale 和协调服务器断开后（MacBook Air 走中继时遇到过），其实仍然连得通，却显示离线，切换器打不开它，它的完成和审批提醒也收不到。每台电脑都要更新，不用重启。

## 0.1.2 — 即时切换，其他机器上的事在页面里提醒

每台电脑都要更新并重启 DSH：切出去的那台负责保留各机器的页面，被切到的那台页面里的切换靠新版，TUI 对话的状态也由各自的机器报告。

- 切换不再重新加载。去过一次的机器，页面会留在窗口里，来回切换是即时的，还停在原来的位置；刷新窗口后回到刷新前显示的机器。宽屏上启动几秒后会在后台打开其他机器的页面，任何屏幕上打开切换器时也会提前开始加载。可以在「设置 → 互联 → 切换」里关掉。
- 其他机器上对话完成、失败，或有审批、问题等你时，页面里会弹出提醒，点一下就切过去；已完成的对话还会在切换器上显示绿色数字。系统通知只在页面不在前台时发。手机和桌面 App 不用授权也能看到页面里的提醒。
- TUI 对话（remote-terminals 在终端里跑的 Claude Code 或 Codex）的回合也算：会显示运行中和已完成。以前只认 DSH 自己的回合，所以 Mac mini 上的 Claude Code 跑完了，MacBook 收不到任何提醒。
- 对话开始后才有标题的，提醒里现在也带上标题。

## 0.1.1 — 另一台机器页面上的插件访问那台机器

- 另一台机器的页面上，插件按绝对路径发出的请求（`fetch('/api/…')`、XMLHttpRequest、EventSource、beacon）经那台机器的挂载转过去，remote-agents 的模型选择器能看到那台机器的远程 CLI。只需要更新切出去的那台电脑。

## 0.1.0 — 在侧栏打开其他电脑的 DSH

同一天早些时候以 `dsh-machines` 0.1.0 发布过，还没有别人安装就改了名。装了 `dsh-machines` 的电脑：先移除它，再安装互联并重启 DSH。新旧两个版本用同一个端口（7390），但互相认不出对方，所以每台电脑都要换。

- 侧栏底部的切换器可以就地打开同一 Tailscale 账号下、运行着本插件的其他电脑的完整 DSH，也能切回本机。
- 其他机器上等你审批或回答的问题会在切换器上显示数字并发系统通知；已完成、失败的对话也可以通知（「设置 → 互联」）。
- 在桌面 App 里，拖入、粘贴或用「+」选给另一台机器的文件会上传到那台机器，而不是写成本机路径；文件夹会提示无法发送。
- 可以重启当前页面所在机器的 DSH，立即或等正在运行的任务结束后；页面会自己重连。支持 launchd 服务、macOS 桌面 App 和从终端启动的 `dsh web`。
- 每台电脑都要安装，并在那台重启 DSH。每台会在自己的 Tailscale 地址上开放 7390 端口，只接受同一 Tailscale 用户。
