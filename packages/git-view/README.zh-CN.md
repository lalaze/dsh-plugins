# Git 视图

[English](README.md) | **简体中文**

DeepSeek Harness 对话的 IDE 风格 Git 面板，移植自 [`@xbzbing/dsh-git-panel`](https://github.com/xbzbing/dsh-git-panel) 1.10.0：分支、标签与提交历史图的 **Git 总览**、可提交与 Amend 的**变更记录**、**文件浏览**，以及有改动文件的 Monaco 差异和文件列表上的改动标记。可用于本地工作区，并且与 dsh-git-panel 不同，也能在 Remote Agents 远程工作区中操作 SSH 主机上的仓库。包名：`dsh-git-view`。

## 要求与安装

- DSH `>=0.2.1-rc.2 <0.3.0`，需提供右侧栏与对话 UI 服务；Node.js ≥ 22.15.0。
- 仓库所在机器需安装 Git。macOS 的 `/usr/bin/git` 需要 Xcode Command Line Tools（`xcode-select --install`）。
- **远程工作区需要 `dsh-remote-agents` 0.2.62 或更新版本**，并提供 Git 工作区 API 第 1 版；面板在远程工作区中的文件浏览、文件大小与时间，以及删除未跟踪文件需要 **0.2.64**。请将两个插件安装到同一个 DSH profile。更早版本或未标记 API 版本的实验实现会明确拒绝请求，不会悄悄忽略工作区绑定。本地工作区不需要 Remote Agents。

在仓库根目录构建并安装压缩包：

```sh
pnpm --filter dsh-git-view pack:plugin
dsh plugin --profile web add "$PWD/dist/dsh-git-view-0.2.0.tgz"
```

使用远程功能时，还需在同一份 checkout 中执行 `pnpm --filter dsh-remote-agents pack:plugin`，将新构建的压缩包安装到**同一个 DSH profile**。文件名中的版本以 [Remote Agents 清单](../remote-agents/package.json)为准，不要使用之前下载的旧包。替换已安装插件时请遵循[仓库安装说明](../../README.zh-CN.md#安装插件)。

Web 端重启更新的 profile 并刷新浏览器。Desktop 端先完全退出 DSH，使用应用自带的 `dsh` 命令和 `--profile desktop` 安装，再重新打开；npm CLI 不能管理这个保留 profile。安装单个 `.tgz`，不要安装私有仓库根目录。共享编辑器与本地化工具已打入产物，无需另装公共包。

## 打开 Git 与自动识别运行位置

“对话”旁的 **Git** 标签、右侧栏的 **Git** 页面，以及输入框左侧的 `仓库 (分支)` 标记打开的是同一个面板；插件设置可选择显示在标签页、侧边栏或两者。标记在工作区干净时为绿色，有改动时为橙色。

如果同时安装了 [`@xbzbing/dsh-git-panel`](https://www.npmjs.com/package/@xbzbing/dsh-git-panel)，它的标签、侧边栏页面和输入框标记在所有会话中都改为显示本插件的面板，本插件自己的入口则让位，每种入口只出现一个。该插件只在 DSH 宿主机器上运行 Git，远程工作区在宿主机上只是一个本地锚点目录。两个插件注入的样式类名相同，建议卸载 dsh-git-panel。

无需切换本地/远程模式：

- 普通会话工作目录在 **DSH 宿主机器**上运行 Git，不一定是浏览器所在的机器。
- 位于 `remote-workspaces` 下的 Remote Agents 工作区锚点，通过 Remote Agents 在会话已验证的 SSH 主机和目录中运行 Git、传输文件；Git 标题栏显示主机名。
- 服务缺失或远程目标无法验证时会报错，**不会回退到本地锚点运行 Git**。请先在 Remote Agents 中配置并选择已验证的工作区。Git 操作不需要克隆或同步一份本地副本。

界面跟随 DSH 的英语/简体中文设置，并适配浅色与深色主题。

## 当前功能

| 区域 | 功能 |
| --- | --- |
| Git 总览 | 分支树（**全部分支**、按文件夹分组的本地分支、远程、标签）及领先/落后；可按提交信息或哈希搜索的提交历史图，作者与时间筛选；带引用标记和悬停卡片的提交详情，点文件查看该提交的差异；切换分支、新建与删除标签、撤销或重置（soft/mixed/hard）提交，破坏性操作需二次确认；抓取、快进拉取、推送及发布新分支 |
| 变更记录 | 统计条，已暂存/未暂存分组，逐文件或批量暂存、取消暂存、放弃，支持多选；提交与 **Amend**；贮藏（保存、应用、恢复、删除）；增删行统计；并排差异窗格 |
| AI 生成提交信息 | 参照仓库既有提交风格，用当前会话的模型或设置中固定的模型生成。**生成会把 diff 发送给该模型的供应商。** |
| 文件浏览 | 懒加载目录树，按文件类型显示图标，忽略项半透明；预览代码、Markdown（含 mermaid 图表）、HTML 与图片；以项目根为根，也可跟随所选仓库 |
| 差异 | 统一、并排、变更前、变更后四种视图；语法高亮、词级强调、按需展开上下文、Ctrl/⌘+F 就地查找；图片可缩放、拖拽与全屏 |
| 多仓库 | 识别工作区中的 worktree 与子目录中的独立仓库；总览、变更记录和输入框标记跟随所选仓库 |
| 布局 | 按面板宽度切换三栏、上下堆叠或单栏钻取布局，侧边栏和窄窗口都能用 |
| 对话旁的改动文件 | HEAD 与工作树文件的 Monaco 差异、编辑与保存、合并冲突处理（见下文） |
| 文件列表 | 为本地工作区文件树、Remote Agents 远程文件列表添加改动字母、文件名颜色和目录改动圆点 |

面板跟随 DSH 的语言（简体中文、English、日本語、Español、Français、Deutsch、Русский、Português，其他语言回落为英文）和深浅色主题。面板可见时每 30 秒刷新一次快照，智能体完成一轮回复后和面板自身操作后也会刷新。

### 设置

插件详情页可设置：输入框标记、面板位置（标签页、侧边栏或两者）、默认差异视图、提交图样式（平行线或紧凑）、字号、是否探测 worktree 与子仓库、文件浏览是否跟随所选仓库，以及 AI 生成提交信息（开关、语言、输入预算、输出 tokens、超时，以及可选的固定 provider、模型和推理强度）。命令超时、输出上限、变更列表上限和刷新间隔保存在 profile 中。

### 差异与冲突处理

有改动的受支持代码/文本文件可从 DSH 文件树或 Remote Agents 文件列表在对话旁打开差异。受支持的内置文件预览也会提供 **Git 差异**选项，但不替换默认预览器。**打开文件**可返回其他可用预览器。

Monaco 比较的是 **HEAD 与当前工作树文件**，包含已暂存和未暂存改动。未跟踪文件与空文件比较；已删除文件则以空内容作为工作树版本。

可选择并排/行内模式、自动换行、折叠未改动区域、字号和编辑模式。**保存**或 ⌘/Ctrl+S 写入工作树文件；**暂存**操作处理磁盘上的文件，不包含编辑器尚未保存的文本，请先保存。本地文件 I/O 使用绑定到已验证目录的短生命周期 Node 子进程，并核对文件/目录身份、元数据及内容哈希。替换父目录不能把该进程的数据读写或临时文件清理重定向到替换后的目录。保存采用原子 rename，但没有跨进程的比较并交换（CAS）：不配合的外部写入者仍可能在最终检查到 rename 之间插入修改。这既不是沙箱，也不保证绝对不会丢失并发更新。会话切换工作区后，旧草稿仍然可见，但编辑、保存和暂存会被禁用，直到明确点击重新加载进入新工作区。重新加载会丢弃旧草稿，请先保留需要的改动。

冲突块支持**接受当前**、**接受传入**和**接受两者**（先当前、后传入），保留周围上下文并折叠较远的未改动行。支持普通和 diff3 冲突标记。检查结果后点击**保存并解决冲突**，写入并暂存该文件。仍有冲突标记时此操作禁用；暂存前会核对保存后的文件版本。若保存成功但暂存失败，界面会明确报告部分成功并保留新的已保存版本：请检查错误并重试暂存，不要认为保存已被撤销。普通**保存**仍然只写文件，**暂存**仍是针对磁盘文件的独立操作。解决并暂存一个文件不会自动提交或完成 merge/rebase/cherry-pick；请在面板中提交，或在终端中继续或中止。rebase 期间应按 Git 的冲突两侧语义理解当前/传入，不要直接当作原来的本地/远程分支。

## 凭据与安全

- 继续使用执行机器上已有的 Git credential helper 和 SSH 密钥。Git 不等待交互式密码输入、编辑器或分页器（`GIT_TERMINAL_PROMPT=0`）；没有可用凭据的网络命令会以登录错误失败。请预先配置凭据和提交者身份。
- Git 视图 0.1 保存的 HTTPS 凭据（`$DSH_HOME/storages/dsh-git-view/git-credentials`，明文，权限 `0600`）仍会用于本插件对该主机执行的本地 Git 命令；面板不再提供保存新凭据的表单。**远程凭据从不保存**，请在远程机器上配置 credential helper 或 SSH 密钥。
- 命令以 argv 数组执行，不经过 shell，在仓库根目录运行，并有超时与输出上限。面板不使用 `--force`，不修改 Git 配置。提交、Amend、暂存、放弃、贮藏、切换分支、标签、撤销与重置都是明确的操作；破坏性操作需要二次确认；不会自动推送。
- **放弃未跟踪条目会在确认后直接删除工作区中的文件**；条目本身是 Git 仓库时整批拒绝。远程工作区中，未跟踪条目用 `git clean` 删除，其他文件仅在读取后未被修改时经 Remote Agents 删除。
- 文件浏览与预览只读取仓库或项目根目录内的文件，并先做包含检查；`.git` 不可浏览。远程工作区中不会在远程机器上解析符号链接。
- **AI 生成提交信息会把所选改动的 diff 发送给 DSH 中配置的模型供应商。** 模型调用由 DSH 完成，插件不持有凭据。如不接受，请在设置中关闭该按钮。
- 插件自身不发起网络请求，也不采集遥测；抓取、拉取和推送只在你点击后访问 Git 服务器。列宽等面板偏好只保存在浏览器 localStorage 中。
- 这些是用户直接点击的 Git 操作，不是经过智能体逐工具审批的模型工具调用。它们以执行账户的权限运行。Git 配置、hooks 和 filters 可以执行程序，只应对可信仓库操作。

## 限制

- 每条命令：本地超时 20 秒（网络命令为 6 倍），SSH 上至少 30 秒（网络命令为 3 倍），输出上限 4 MiB；变更列表最多 1,000 项。更大的仓库可能显示截断的数据，面板会注明。
- 远程工作区中每条 Git 命令都是一次 SSH 往返，文件大小与时间按目录各读取一次列表，因此比本地慢。仓库根目录位于工作区目录之上时，远程无法查看图片差异。
- 远程工作区的文件不能用本机的桌面应用打开。
- 不提供 clone/init、按代码块暂存、交互式变基或远程仓库管理。

### 与 dsh-git-panel 的关系

`src/gp/` 下的面板源码来自 [`@xbzbing/dsh-git-panel`](https://github.com/xbzbing/dsh-git-panel) 1.10.0（MIT），提交 `3e7c566`，改动如下：请求发往本插件的 `POST /api/git-view/gp` 路由，而不是 typert 服务；命令与文件读取经本插件的本地执行器或 Remote Agents 执行（`src/gp-host.ts`）；标识、语言命名空间和设置改为本插件的；移除 GitHub 版本检查。见[第三方声明](THIRD_PARTY_NOTICES.md)。用它自带的单元测试检验了这份副本：730 项中 709 项通过；其余 21 项检查的是它的包标识与构建产物、发布文件、RPC 传输和版本检查，这些正是本副本替换的部分。

## 开发检查

使用仓库根目录的依赖和固定 pnpm 版本，约定见[开发指南](../../docs/development.md)。在仓库根目录执行：

```sh
pnpm --filter dsh-git-view typecheck
pnpm --filter dsh-git-view test
pnpm --filter dsh-git-view build
# 或一次运行上述三项：
pnpm --filter dsh-git-view check

# 共享编辑器和同 checkout 的远程集成：
pnpm --filter @dsh-plugins/file-view check
pnpm --filter dsh-remote-agents check
pnpm --filter dsh-git-view pack:plugin
```

测试脚本包含服务端/解析器测试、面板宿主的本地与远程适配测试，以及 React/jsdom 客户端测试；客户端测试通过 `test/support/` 替代 DSH 的 UI 基础组件。该包没有 `test:ui` 脚本。确定性的[本地文件安全测试](test/files-safety.test.ts)覆盖目录/根目录替换、文件身份与内容变化、临时文件篡改、取消与清理、别名并发保存、权限、编码和大小限制。这些检查无法消除上文所述最终检查到 rename 之间的竞争窗口。发布前检查压缩包中的服务端/客户端入口、按需编辑器及其声明、双语 README 和许可证。在可丢弃的本地仓库及已验证远程仓库中，手动检查面板的三个标签页、分支切换、提交与 Amend、放弃、差异、冲突保存/暂存、文件标记与登录失败，并覆盖两种语言和主题。这是应执行的检查清单，不代表已经验证全部宿主或流程。
