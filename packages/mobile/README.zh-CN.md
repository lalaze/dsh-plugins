# DSH Mobile

[English](README.md) | **简体中文**

支持英文和简体中文：设置页跟随 DSH 的语言设置，手机应用跟随手机的语言。

`dsh-mobile` 让你像使用 Paseo 的手机应用一样，在任何地方用手机查看并指挥你的机器上的 DeepSeek Harness 会话。手机经中继连接，机器和手机都不需要开放端口或使用 VPN。手机与机器交换的一切都经过端到端加密，中继只转发它无法读取的字节。会话始终在机器上执行，使用它的文件和登录状态，包括使用 [Remote Agents](../remote-agents/README.zh-CN.md) 远程 CLI 的会话。

## 手机上能做什么

- **会话**：与 [Workspace Tags](../workspace-tags/README.zh-CN.md) 在 DSH 侧栏中“按状态分组”的方式一致：**等待你处理**、**已完成**（你上次查看后完成的，在手机或共享这个会话的电脑上看过都算）、**运行中**、**空闲**（默认折叠）。有会话在运行的工作区整个归入“运行中”。工作区保持侧栏顺序并显示标签色点；会话保持工作区内的顺序，每次显示 5 条，其余可 **展开**，每条前面是模型图标。等待你处理的会话在标题下写明它在问什么。标签芯片可把列表限定到某个标签；搜索在放大镜按钮后面，已归档会话、子智能体和不在工作区中的会话可从“显示选项”中打开。与 DSH 一样，空白会话和不在任何工作区中的会话默认隐藏。下拉列表可重新连接并刷新；长按会话可重命名或归档。打开会话再返回时，列表保持原来的位置。配对多台机器后，各机器的会话会一起显示。
- **对话**：从最新处开始阅读，向上滚动时自动加载更早的消息，有按钮可回到最新处。回复按 Markdown 显示，代码块带复制按钮，思考过程折叠，每轮显示用时和复制按钮；点击图片全屏查看。每次工具调用占一行，写明做了什么、对什么做的（命令、文件、搜索），连续的调用合并为一组；点击可看详情：命令及其输出、编辑的差异、计划清单。回复在生成过程中实时显示，中途打开或重连也能看到已生成的内容。DSH 注入的上下文（工作区说明、技能目录、时间快照）与 DSH 中一样保持隐藏。
- **指挥**：发送消息，可附带图片（先在手机上缩小）。任务运行中发送消息会用你的消息打断它，与 Paseo 一致；输入框为空时，按钮用于停止任务。输入框下方的标签显示会话的模型、思考强度和权限，可从中切换模型或思考强度。待批准的工具调用（附带完整命令）和问题固定在输入框上方，按钮更大。发出的消息立即显示；没发出的草稿按会话保留。点击标题可重命名或归档会话。手机的返回手势会先关闭打开的面板，再离开当前页面。
- **新建会话**：与 Paseo 一样先写任务，再选择工作区（最近用过的一点即选）以及下方标签中的模型、思考强度和权限预设。配对了多台机器时，可以选择在哪台上运行。
- **后台任务**：机器上装有 [Remote Agents](../remote-agents/README.zh-CN.md) 0.2.67 或更高版本时，没有 DSH 对话的远程 CLI 会话（例如 DSH 智能体分派的任务、从 **打开会话** 启动的会话）列在 **后台任务** 中，等待处理的排在最前，其次是运行中的。打开后可以查看历史、实时跟随运行、发送消息（运行中发送会打断它）、停止任务或批准工具调用。分派出来的任务会链接到分派它的对话。Claude 的安全机制拦截请求、Claude Code 换了模型时（需要 Remote Agents 0.2.83 或更高版本），历史里会在发生的位置写明换成了哪个模型。
- **通知**（可选）：任务完成或会话需要你处理时通知，应用关闭时也会通知。正在屏幕上显示的会话不再弹出通知。

每个请求都带有 ID，连接中断后重试也不会重复执行。应用会自动重连并补上错过的内容。

## 要求

- DSH 0.2.1-rc.3 或之后的 0.2 版本，所在机器在你使用手机期间保持开机。会话在这台机器上执行。
- 一个支持 Paseo 中继协议（v2）的中继，例如自托管的 Paseo 中继。插件使用自己的服务器 ID 连接，可以与 Paseo daemon 共用同一个中继。
- 通过 HTTPS 托管的手机应用（见下文）。
- 在 iPhone 上使用通知：iOS 16.4 或更高版本，并把应用添加到主屏幕。

## 设置

1. 安装插件并重启 DSH。
2. 打开 **设置 → 手机访问**，填写：
   - **中继**：`主机:端口`，例如 `relay.example.com:443`。默认使用 TLS，除非写成 `ws://`。旁边的状态显示本机是否已连接。如果中继只接受已知的服务器 ID，请在中继上放行这里显示的 **服务器 ID**。
   - **手机应用地址**：手机应用的托管地址，例如 `https://dsh.example.com/`。
3. 选择 **配对手机**，用手机相机扫描二维码（或在手机上打开链接）。二维码只能使用一次，10 分钟后过期。
4. 手机和设置页会显示相同的六位数字。核对后选择手机的权限，再选择 **允许**。

在 iPhone 上，请先把应用添加到主屏幕（分享 → 添加到主屏幕），再从主屏幕打开并开启通知。主屏幕应用有独立的存储，所以请在应用内配对：点 **扫描二维码** 或粘贴链接。

### 托管手机应用

`pnpm --filter dsh-mobile build` 会把应用输出到 `packages/mobile/lib/app/`。这些是静态文件，可以放在任意 HTTPS 主机上（子路径也可以）。应用只与中继通信，托管主机看不到你的数据。

如果只想先试用、暂不托管，可以使用此 DSH 自己的地址加上 `/api/dsh-mobile/app/index.html`（**使用此 DSH** 会自动填入）。这个副本只能在已登录此 DSH 的浏览器中打开，适合同一 Tailscale 网络中的手机，不适合在外面的手机。

## 手机与权限

每台已配对的手机都会列出：是否在线、最近在线时间、是否开启通知。每台手机可以分别设置：

- **查看会话**：工作区、对话和附件。
- **指挥会话**：发送消息、停止任务、回答审批和问题，以及新建、重命名和归档会话。

两项都可以随时修改；**解除配对** 会立即断开这台手机，之后也会拒绝它。允许指挥的手机在线或开启了通知时，也会收到 DSH 的工具审批：审批会同时发给它和本机的浏览器，先回答的一方生效。

## 安全

- 配对码中包含机器的公钥，所以手机知道自己在和谁通信；中继或任何中间人都无法冒充这台机器。
- 每台手机都有自己的密钥，在手机上生成。机器只接受已配对的密钥，配对需要你核对六位数字；两边的数字都由双方密钥和一次性令牌计算得出。
- 每次连接都会用 X25519（长期密钥和临时密钥）经 HKDF-SHA256 派生新的 AES-256-GCM 密钥。帧带编号，丢失、重复或乱序的帧都会结束连接。
- 通知会针对手机浏览器加密（Web Push，RFC 8291），由机器使用自己的 VAPID 密钥直接发送到手机的推送服务。
- 手机把自己的密钥和已配对的机器保存在应用的本地存储中。可在手机的 **设置** 中移除机器，同时也请在机器上解除配对。

## 配置

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `relay` | 无 | 首次设置使用的中继，之后可在设置页修改 |
| `appUrl` | 无 | 首次设置使用的手机应用地址 |
| `stateDir` | `~/.dsh/storages/dsh-mobile` | 存储目录（设置了 `DSH_HOME` 时位于其下） |

## 如何使用 DSH

- 会话通过 DSH 的会话控制器读取（`list`、`follow`；读取完整日志时，DSH 0.2.2 之前用 `inspect`，之后用 `sessionQuery`。读取日志时不会启动智能体），并通过它的 `prompt`、`cancel`、`create`、`selectModel` 和 `rename` 指挥。归档通过工作区控制器，回答问题通过 `userQuestions`，权限预设通过 `permissionPresets`。
- 后台任务来自同一台机器上 Remote Agents 的 `remoteAgentsTasks` 服务；没有它时不显示这一栏。
- DSH 没有供其他设备回答工具审批的接口。插件加入 DSH 的 `approval/request` 链：审批同时发给手机和本机的浏览器，先回答的一方生效；任何失败都不会改变 DSH 自己的审批链。

## 限制

- 每台手机同一时间只能接收一台已配对机器的通知，因为浏览器只能持有一个推送密钥。
- 后台任务只能发送文字，不发通知，其中的提问需要在电脑上回答。
- 只有 DSH 的 `ask_user_question` 开启 `mode: timed` 时，问题才会显示到手机，默认的阻塞模式不会。目前也无法在手机上回答，请在电脑上回答。
- 超过 16 MB 的附件无法在手机上打开。
- 已有会话的权限预设只显示、不能在手机上修改；DSH 只能在会话运行时修改它。
