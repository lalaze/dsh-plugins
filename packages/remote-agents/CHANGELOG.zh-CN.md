# DSH Remote Agents 更新日志

[English](CHANGELOG.md) | **简体中文**

按版本从新到旧列出变化及升级后需要做的事。

**从 0.2.103 升级：** 新建的对话如果继承了当前工作区运行不了的远程模型，现在会换成一个能运行的模型，不再在发第一条消息时报错。在本地工作区，它用你最后选的本地模型；在另一台机器上，它用那台机器上相同的 CLI 和模型。只有这个对话会变，你的默认模型仍是你最后选的那个。

**从 0.2.102 升级：** Claude 运行工具时显示的那一行现在和 DSH 自己的工具行一样，用相同的灰色和星形图标，不再是带竖线的引用。内容类似 `工具调用 · Run the tests`，只有没有别的内容可显示时才写工具名。太长时截断在一行内。请同时把 `dsh-mobile` 更新到 0.3.7，旧版手机端会把这一行显示成打不开的链接。

**从 0.2.101 升级：** `/team`、设置里的 **团队预设** 和让 TUI 对话当队长的功能已移除，因为安排团队是 AgentTeams 的事。请用 `/agent-teams` 启动团队，远程 CLI 仍可作为成员，已保存的预设会被丢弃。结束的子智能体不再把 CLI 留在远程机器上；以前这可能占满账号的 32 个名额，导致 CLI 无法启动。之后再给这个子智能体发消息会恢复它。本地隧道不再监听所有网络，只监听本机和你的浏览器访问 DSH 用的地址；从这台电脑启动的隧道，要在手机上停止并重新启动后才能从手机打开。新工作树带来的、表单里没有显示过的初始化命令，现在会等你选择，不会直接运行。现在只有连接失败才会把机器标记为失败。

**从 0.2.100 升级：** 已读状态现在会在设备之间同步。在一个 DSH 里打开对话，几秒内共享这台机器的其他 DSH 上的 **已完成** 标记就会消失，手机上也一样（需要 `dsh-mobile` 0.3.6）。DSH 窗口在前台且有焦点时才算看过，所以你离开时跑完的回合，手机上仍会标记。每个 DSH 都要升级到这个版本，它的已读才算数；升级前打开过的对话要再打开一次，标记才会消失。无需操作。

**从 0.2.99 升级：** TUI 对话右下角多了一个小按钮，里面有两个开关，终端觉得卡时可以试试。**WebGL 渲染**改用 GPU 绘制终端，在 M4 Mac mini 上全屏重绘时 CPU 占用降到约四分之一。**背景模糊**可以关掉终端背后的模糊，它占用了这块 GPU 的 8% 到 9%。切换立刻对这个浏览器里所有 TUI 生效，选择也会记住。不动开关就没有变化：默认 WebGL 关、模糊开。开启 WebGL 后文字窄约 4%，一行能多放几个字符。WebGL 不可用或中途失效时，终端继续用普通渲染，菜单里会说明。无需操作。

**从 0.2.98 升级：** **设置 → 远程智能体** 里的团队预设更容易看懂了，也能选每位成员的思考强度。这个字段以前就有，但设置页比表单窄，被裁掉了。现在模型和思考强度都是下拉框，模型留空时也能选强度。页面顶部列出了从预设到团队运行的三个步骤，编辑时能看到团队会怎么运行：哪项任务先做、谁用什么模型做、谁等谁。没有任务的成员不会开工，页面会提示并可以一键补上任务；任务互相等待时也会提示。改任务 id 或删除任务时，等它的任务会跟着更新；以前删掉被依赖的任务后，预设就存不了了。已有预设不受影响。无需操作。

**从 0.2.97 升级：** Claude 运行工具时显示的那一行更短、更好读了。Bash 命令现在显示 Claude 写的一句话说明，比如 `正在运行 Bash · Push branch and run market release`，不再显示命令的开头。以前长脚本的内容会被压成一行再截断，还经常单独掉到下一行。Claude 没写说明时显示命令的第一行；文件路径太长时保留结尾的文件名。完整命令和以前一样，在回复结束后的工具卡片里。无需操作。

**从 0.2.96 升级：** 切回 TUI 对话不用再加载了。以前每次切回都要先和远程机器通信一次，再重建终端，中间有一段空白；现在最近用过的 6 个终端切走后不关闭，继续跟着 CLI 更新。其余的终端重新打开时还会短暂空白，但不用再和远程机器通信。DSH 重启或连接断开后，第一次切回仍会短暂显示“正在启动”。文件在你切走之后才上传完的，路径会立刻填进它所在对话的输入框，不再等你切回来。

**从 0.2.95 升级：** 远程终端和 TUI 对话现在关掉 DSH、电脑休眠或断网时都会在远程机器上继续运行。回复会在 DSH 不在时接着写；重开 DSH 或网络恢复后，看到的还是同一个进程，屏幕和滚动记录都在，断线会自动重连。侧栏的终端标签在重启后也会自己回来。关闭标签、`exit` 或归档 TUI 对话仍会结束里面运行的东西；一直没人回来的终端 7 天后结束。这要求远程机器有 Python 3 和 Node.js 22，不用额外安装别的；没有的机器照旧用普通连接，并在终端里提示。已经开着的终端要到下次打开才生效。打字也更轻了：这些连接关掉了 OpenSSH 的按键节奏保护，它每个按键发的数据约是 9 倍（327 字节对 36 字节），在丢包的线路上会让打字卡住。代价是网络上的观察者能从包的时间看出打字节奏，和 OpenSSH 9.5 之前一样。
**从 0.2.94 升级：** Claude 对话运行时能看到更多内容。Claude 在工具调用之间写的简短进度说明，以前折叠在“已完成分析”里，现在会实时显示在回复中，并保留在最终回复里，所以长回复会变长一些。回复底部还会多一行，显示 Claude 正在运行的工具，比如 `正在运行 Bash · npm run build`。工具跑完这一行就消失，也不会被保存。工具卡片仍在回复结束时出现。子智能体和团队成员的回复就是它们的结果，所以进度说明仍然折叠。Codex 和其他 CLI 不变。如果你在用 dsh-mobile，请一起更新到 0.3.5：0.3.4 上这些状态行会在手机上一直叠加，直到回复结束。

**从 0.2.93 升级：** TUI 对话的状态现在会显示在侧栏：CLI 干活时显示运行中，弹出权限确认或提问时显示等待你处理，干完且你没在看时显示已完成。无需设置。状态来自 Claude Code 和 Codex 的终端标题、状态信号和屏幕，不额外连接远程机器，所以只有终端开着才知道；DSH 重启后要等你重新打开这一行。想把完成的任务集中显示在最上面，请同时把 dsh-workspace-tags 更新到 0.2.2，并选择按状态分组。

**从 0.2.92 升级：** TUI 对话现在能当团队队长，Claude Code 和 Codex 都可以。装了 `dsh-agent-teams` 时，在终端里直接输入 `/team …`（和聊天里一样），或者告诉 CLI 要分工，它会用新增的 `start_team` 工具发起。成员的汇报会自动作为消息进入终端，CLI 也能查看团队、给成员发消息、调整任务和删除团队。输入框里有草稿或 CLI 正在问你问题时，汇报会等着，因为这时回车可能误答弹窗，右上角有提示。已经在运行的 TUI 要到下一个终端才有团队工具；在那之前，输入 `/team` 和接收汇报都能用。其他功能不变。无需操作。

**从 0.2.91 升级：** 启动 Codex TUI 的按钮和拖文件时的提示，从简单的 `>_` 换成了 Codex 的图标。无需操作。

**从 0.2.90 升级：** TUI 对话现在也能跑 Codex。在远程工作区新建对话，选一个远程 Codex 模型，点输入框左下角的 `>_`。拖放和粘贴文件与 Claude Code 一样，重启 DSH 后这一行会接回同一个 Codex 线程，模型不变。标题优先用在 TUI 里 `/rename` 改的名字，其次是第一条消息，因为 Codex 不会给这些线程自己起标题。Codex 不用它自己的全屏模式，这样滚轮能翻看对话；也不显示启动时的更新提示，因为第一个回车就会直接安装，要更新请在远程运行 `codex update`。原生终端的 Shell 菜单里也多了 **Remote Codex**。无需操作。

**从 0.2.89 升级：** TUI 对话可以接收文件了。把文件拖到窗口里或粘贴进来（Cmd+V；图片也可以用 Ctrl+V），文件会上传到远程项目的 `.dsh-remote-agents/attachments/tui/`，路径填入 Claude Code 的输入框，图片显示为 `[Image #1]`。每个文件不超过 50 MB，不支持文件夹，传上去的文件不会自动清理。以前把文件拖到 TUI 对话上，文件会进到一个隐藏的输入框，Claude Code 根本收不到。另外，上传到远程项目的附件（包括聊天附件）现在由 `.dsh-remote-agents/` 里的 `.gitignore` 排除在 Git 之外。无需操作。

**从 0.2.88 升级：** 修复实时显示的一轮在发起它的 DSH 掉线（比如笔记本休眠）时提前结束：以前对话约一分钟后就把这一轮当作结束，后面的内容再也不显示。现在会等到另一个 DSH 接管 CLI，一直显示到这一轮结束。如果对方状态中断后两分钟内没有人接管，回复里会说明，之后的输出仍会补上。无需操作。

**从 0.2.87 升级：** 另一个 DSH 正在同一个 CLI 会话里跑的一轮，现在会在这里的对话中实时显示，不再等结束后一次性补上。对话显示为运行中，在这里点停止会停掉这一轮。闲置了一段时间、或 DSH 重启后还没有智能体的对话也一样。工具调用那一行仍在这一轮结束时出现。在手机上看，需要给手机连接的那个 DSH 装 `dsh-mobile` 0.3.4；其他情况无需操作。

**从 0.2.86 升级：** TUI 对话的观感再调整。字号退回 DSH 默认的 13px（在 DSH 设置里调过的大小照旧）；内容列收窄到约 900px；背景从 0.62 改成 0.92 不透明度，只留一层很淡的壁纸质感，复杂壁纸上不再发脏；中文不用装字体，把系统中文字体放大 12% 填满两格，字距不再发散。

**从 0.2.85 升级：** 修复停止回复后，下一条消息开头突然出现 `Output from the previous response, completed while DSH was disconnected:`、后面却什么都没有。这句话现在只在 DSH 确实断开过、而且有内容要显示时才出现；重新打开停止过的对话也不再提示同步。同时修复两个相关问题：消息发出后立刻停止，这一轮之后不会再显示成 `1 turn sent elsewhere`；已经看到的远程 CLI 错误不会带着这句话再显示一遍。停止那一刻还没读到的最后一小段文字不再补到下一条回复里，仍可在**打开会话**中查看。更新前停止过的对话，重新打开时可能还会出现一次同步提示；如果当时还有没读到的文字，可能带着这句话显示一次。更新后请重启 DSH。

**从 0.2.84 升级：** TUI 对话更好看，也修了左侧图标。终端内容收在和聊天区差不多宽的中间列，背景半透明，能透出壁纸；字号至少 14px，在 DSH 设置里调得更大时不受影响；Claude Code 改用真彩色，吉祥物和强调色不再偏粉。已打开的 TUI 要结束后重新打开，真彩色才生效。修复 TUI 对话在左侧没有模型图标：只沿用输入框记住的模型、没有手动选过时，模型不会写进会话，现在启动时会写入，已有的 TUI 对话选中后也会补上。

**从 0.2.83 升级：** 修复 TUI 对话的标题一直停在 `Claude Code`：Claude Code 不是每次都起标题，短消息（比如 `hello`）通常没有。现在没有标题时用第一条消息，和其他对话一样；Claude 之后起了标题会再替换，在 TUI 里用 `/rename` 改的名字优先，在 DSH 里手动改过名的不会被覆盖。已有的 TUI 对话选中后也会更新。

**从 0.2.82 升级：** Claude 的安全机制拦截一次请求时，Claude Code 会换一个模型重试，后面的轮次也继续用它，而模型选择器仍显示你选的模型。以前 DSH 对此没有任何提示；现在回复和**打开会话**会在发生的位置写明换成了哪个模型，以及怎么换模型；手机的后台任务页也会显示，需要 `dsh-mobile` 0.3.3。使用量统计也改为按实际模型分别计入：以前一轮用到多个模型时整轮都算给最后一个，所以 Fable 5.1 回退之前的用量会被算成 Opus 4.8。Claude 子智能体的用量现在也会计入，所以总量和调用次数可能比以前略高；已有记录不变。不上报各模型用量的旧版 Claude Code 仍按原来的方式统计。更新后请重启 DSH 并刷新客户端。

**从 0.2.81 升级：** TUI 对话更顺手。启动按钮换成 Claude 吉祥物图标，只有选了远程 Claude 模型才显示；点开后用你选的模型和思考强度启动。标题不再固定为 `Claude TUI 时:分`：先显示 `Claude Code`，之后跟随 Claude Code 给对话起的标题（在 TUI 里用 `/rename` 改的名字优先），已有的 TUI 对话选中后也会更新；在 DSH 里手动改过名就不再覆盖。

**从 0.2.80 升级：** 新增 TUI 对话：在远程工作区新建对话，点输入框左下角的 **用 TUI 开始**，「对话」标签页就变成交互式 Claude Code，左侧列表多一行，选中哪行就显示哪个 TUI。切走时 Claude 继续运行；重启 DSH 后再选中会接回同一个 Claude 会话，但正在跑的那一轮会中断；归档这一行会结束它的 Claude。对话内容只在远程的 Claude Code 里，DSH 的对话记录和手机端看不到。另外修复了 `DSH_HOME` 不是默认目录时，Remote workspace 和 Remote Claude 终端找不到远程工作区、退回本地 shell 的问题。

**从 0.2.79 升级：** 原生终端的 Shell 菜单新增 **Remote Claude**：选它会在当前远程工作区直接启动交互式 `claude`，拿到完整的 Claude Code 终端界面，退出后留在远程 shell。这个会话不会显示在 DSH 对话里，也用不到 DSH 共享的 MCP 服务和技能，之后在远程目录运行 `claude --resume` 继续。

**从 0.2.78 升级：** 远程智能体设置页更顺手，功能不变。远程机器列表默认折叠：每台机器只占一行，显示名字、连接、状态、是否共享和模型数，并用一行小字概括启用了哪些 CLI；展开后才显示共享开关和各 CLI 的勾选。每台机器的 测试连接、刷新模型、移除 收进右侧的 ⋯ 菜单。有机器时"添加机器"表单收起成一个按钮，需要时再展开；没有机器时照旧直接显示。团队预设的成员和任务改成可折叠的卡片，编辑已保存的预设时默认收起、只看摘要，新建预设或新加的成员/任务自动展开。更新后请重启 DSH 并刷新客户端。

**从 0.2.77 升级：** 新增 `/team` 命令：在远程工作区的对话里输入一行，例如 `/team pair coder=codex reviewer=claude/opus 修复登录超时`，就能用 NanmiCoder 的 dsh-agent-teams 启动一个成员是远程 CLI 的团队并立刻开始工作。以前要先让队长规划一轮、在计划页逐个成员选模型、点确认后再等队长被唤醒一轮；现在插件替这个对话直接创建团队，回车后成员就领到任务，队长在成员汇报时才参与。成员写成 `名字=cli[/模型][@思考强度]`，模型在工作区所在机器上按 id 或名称查找；`coder=captain` 让成员用队长的模型。内置 `solo` 和 `pair` 两个预设，**设置 → 远程智能体 → 团队预设** 里可以保存自己的阵容和任务模板。加 `--plan` 仍可先在团队面板里审计划。详见 [一行启动团队](README.zh-CN.md#一行启动团队)。更新后请重启 DSH 并刷新客户端。

**从 0.2.76 升级：** 远程 Claude Code 的对话现在会显示 Claude 自己进行的轮次：它跑的后台任务（例如放在后台运行的命令或子智能体）完成后接着做的那一轮，或到了它自己定的唤醒时间做的那一轮。之前 Claude 确实会接着做，但 DSH 当会话是空闲的：输出只存了下来没有显示，Claude 工作时会话显示为**就绪**，期间发的消息还可能收到另一轮的输出。现在这样的一轮结束后会补成一块显示，标题为 **Claude 自行继续了 1 轮**，并附上 Claude 收到的通知；进行期间会话显示为运行中，期间发的消息会像在 Claude 终端里输入那样等它结束再发，排在这一轮之后。**打开会话**里同样显示这一轮和通知。见[在 DSH 主对话中使用](README.zh-CN.md#在-dsh-主对话中使用)。更新后重启 DSH。

**从 0.2.75 升级：** 远程 CLI 的操作更快、占用内存更少，功能不变。每次操作前复查机器身份和取主目录不再加载远程登录 shell，短暂空闲后的第一次操作不再先卡半秒。开始一个对话只探测你选的那个 CLI，而不是把每个已启用的 CLI 都启动一遍来列模型。登录 shell 导出的环境会在主机上缓存约一分钟，一连串命令只付一次 shell 启动开销；在 shell 配置里改动的值最多一分钟后生效。在中继下运行的远程 CLI 现在由中继在有新输出时通知即读，不再轮询。在界面上看过的会话历史，一段时间无人读取后从内存释放，再次读取时按需从磁盘重新载入。后台中继脚本有变化，下次连接时会自动重装；更新后请重启 DSH。
